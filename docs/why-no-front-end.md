# Why no front end

The work is records, links, dates and evidence. A coding agent can operate the CLI and present answers without another application to maintain. The same database works with Claude Code, Codex, OpenCode and Cursor.

A screen gives people mobile entry, shared access, guided forms, file upload, notifications and real-time collaboration. This base gives a trusted operator commands, printable documents and read-only HTML snapshots. It has no offline mobile synchronisation, validated signatures, image inspection or statistical process control engine. A saved dashboard is a snapshot, not a live portal.

For general manufacturers whose quality manager keeps these records, it is a useful starting point. For regulated release, validated electronic records or a team dependent on mobile entry, do not treat this base as a complete replacement. Enterprise DNA scopes the required system and integrations before a move. The custom version can include a web front end and a different database stack. Nothing here sends a message or releases a batch.

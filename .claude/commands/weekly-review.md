description: Prepare the Monday quality review
---

1. Run `npm run quality -- attention --json`, `npm run quality -- supplier-review --json`, `npm run quality -- training-due --json` and `npm run quality -- repeat-failures --json`.
2. Write the review to `drafts/weekly-review.md`: urgent actions, recurring defects, suppliers to review and training to complete. Name owners and dates from the records.
3. Separate recorded facts from proposed actions. Do not mark anything complete or send anything.
